How the Cryptographic Posture Score is Determined

Cyber Tech calculates an objective, multi-factor Cryptographic Security Posture Score on a scale from 0 to 100, evaluating five critical dimensions of network and email cryptographic health:

30 PTS

1. Protocol & STARTTLS Integrity

  • +30 Points: Modern TLS 1.3 negotiated.
  • +24 Points: Robust TLS 1.2 negotiated.
  • +6 Points: Deprecated TLS 1.0 / 1.1 (vulnerable to downgrade).
  • 0 Points (IMMEDIATE CRITICAL): Active STARTTLS stripping detected, or cleartext credentials (AUTH LOGIN) transmitted over unencrypted SMTP/POP/IMAP.
25 PTS

2. Cipher Suite Strength & AEAD

  • +25 Points: Modern Authenticated Encryption with Associated Data (AEAD) ciphers (e.g. AES-256-GCM, CHACHA20-POLY1305).
  • +15 Points: Acceptable non-AEAD suites with CBC mode.
  • 0 Points: Weak or broken ciphers: 3DES Sweet32 (CVE-2016-2183), RC4-128, DES, or NULL ciphers.
25 PTS

3. Key Exchange & Perfect Forward Secrecy

  • +25 Points: Ephemeral Diffie-Hellman (ECDHE / DHE), ensuring session traffic cannot be decrypted even if server private keys are later compromised.
  • +5 Points: Static RSA key exchange without Forward Secrecy.
20 PTS

4. Certificate Hygiene & Validity

  • +20 Points: Trusted, unexpired certificate with public key $\ge 2048$-bit RSA or ECC P-256/P-384, and SHA-256/SHA-512 signatures.
  • -10 Points: Expired certificate.
  • -5 Points: Untrusted self-signed certificate.
  • -5 Points: Weak SHA-1 or MD5 certificate signature hash.
-10 PTS MAX

5. AI/ML Unsupervised Isolation Forest Anomaly Penalty

The unsupervised machine learning engine detects exotic deviations from typical baseline email traffic. Deduces up to 10 points based on anomaly severity:

  • Single-cipher advertisements typical of stealth lightweight Command & Control (C2) malware.
  • Missing Server Name Indication (SNI) extension in modern TLS streams.
  • Unusual elliptic curve parameters or non-standard ClientHello extensions.
